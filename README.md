# Tetris - 俄罗斯方块

经典俄罗斯方块网页游戏，带账号系统、体力机制、排行榜和道具商城。

## 功能特性

- **账号系统**：注册/登录，数据本地存储
- **体力机制**：每局消耗 10 点体力，自动随时间恢复
- **道具商城**：一键清屏、体力恢复、复活道具
- **排行榜**：本地 TOP 10 高分榜
- **游戏设置**：可调节方块下落速度、背景音乐开关
- **触屏支持**：移动端触摸操控
- **暂停/继续**：游戏中途可暂停

## 在线游玩

直接访问：**[danyuyu211.github.io/naiwa-tetris](https://danyuyu211.github.io/naiwa-tetris/)**

## 本地运行

浏览器直接打开 `index.html` 即可游玩，无需任何构建工具。

## 操作方式

| 按键 | 操作 |
|------|------|
| ← → | 左右移动 |
| ↓ | 加速下落 |
| ↑ | 旋转方块 |
| 空格 | 一键落底 |
| P | 暂停/继续 |
| C | 使用清屏道具 |

## 技术栈

纯原生 HTML/CSS/JS，零依赖，数据存储使用浏览器 localStorage。
